# 👨‍💻 CRUD de Usuarios - Angel Rivera

Aplicación web desarrollada con JavaScript que permite gestionar usuarios (crear, editar, eliminar y visualizar).

## 🚀 Funcionalidades

- ➕ Crear usuarios
- 👀 Ver lista de usuarios
- ✏️ Editar usuarios
- ❌ Eliminar usuarios
- 💾 Guardado en localStorage

## 🛠️ Tecnologías

- HTML
- CSS
- JavaScript
